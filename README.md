### Sobre

Construo skills de agente e automações, e ensino devs e criadores a entregarem com elas.

- 🎥 **[YouTube](https://www.youtube.com/@oandersonadelino)** — IA, agentes e automação
- 📸 **[@andersonadelino.ia](https://instagram.com/andersonadelino.ia)** — versões curtas, mesmos temas
- 🧰 **[skills](https://github.com/AndersonAdelino/skills)** — minhas skills de Claude Code, livres e open source

### Currently shipping

**[cut-silence](https://github.com/AndersonAdelino/skills/tree/master/skills/cut-silence)** — cuts the dead air out of talking-head video and normalizes the audio to -16 LUFS. Runs offline, costs nothing.

```
/plugin marketplace add AndersonAdelino/skills
/plugin install adelino-skills@adelino
```

More skills landing gradually.
